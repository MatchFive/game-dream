# GameDream Core + Godot Vertical Slice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the deterministic core pipeline that turns a fixture GameSpec + genre template into a bootable Godot project with four local modules, and prove it with a headless boot/inventory test.

**Architecture:** TypeScript monorepo. `@gamedream/core` owns schemas, local module registry, resolver, and composer. `@gamedream/godot` detects/imports/runs Godot. `@gamedream/cli` exposes `doctor`, `compose`, `run`, and `verify`. The generated project separates composer-owned `game/_generated/` from user-owned `game/`. No LLM or MCP in this plan; those are Plan 2.

**Tech Stack:** Node.js 22+, TypeScript (strict, ESM), pnpm workspaces, Zod, YAML, semver, Commander, execa, Vitest, Godot 4.4+ (GDScript).

**Spec:** `docs/superpowers/specs/2026-11-12-gamedream-design.md`

## Global Constraints

- Node.js **>= 22**; TypeScript **strict**, **ESM** (`"type": "module"`), `module`/`moduleResolution` = `NodeNext`.
- Package manager: **pnpm** via `corepack pnpm`. Do not commit lockfiles generated by npm/yarn.
- Godot **4.4+**; GDScript only. Godot binary is resolved from `GODOT_BIN`, then `godot`, then `godot4`.
- Fixture template id: **`fixture-minimal`**.
- Fixture module ids exactly: **`core.events`**, **`core.stats`**, **`system.inventory`**, **`ui.hud`**.
- Generated project boundaries:
  - `modules/` = managed by composer, read-only for users.
  - `game/_generated/` = managed by composer, rebuilt on compose.
  - `game/content/`, `game/config/`, `game/scripts/`, `game/ui/`, `game/tests/` = user-owned, never overwritten.
- `game/game.manifest.json` records managed/user globs and hashes.
- Compose is **idempotent**: running it twice with the same inputs must not change user files or rewrite unchanged managed files.
- All generated text files are **UTF-8 with LF** line endings.
- Windows-first; always build paths with `node:path`; tests use temp directories containing spaces.
- License: **Apache-2.0**.
- No LLM calls, no network calls, no MCP addon in this plan.

## Review Focus

These are the failure modes most likely to bite a user that the fixture tests must pin down:

1. **Godot missing or wrong version** — `doctor` and `verify` must report `skip`/`fail` with an actionable message, never a false `pass`. Owning task: Task 9 (adapter) and Task 10 (CLI verify).
2. **Composer overwrites user work** — a second `compose` must preserve `game/content/items/keep.json` and other user files byte-for-byte. Owning task: Task 7/8.
3. **Dependency errors** — missing module, missing dependency, cycle, conflict, engine mismatch must fail with stable error codes, not hang or silently drop a module. Owning task: Task 5.
4. **Windows path/encoding** — project directories with spaces, backslashes, and non-ASCII names must compose correctly; generated files must be UTF-8/LF. Owning task: Task 7/8/11.
5. **Godot import/autoload order** — `Game` autoload must come before module autoloads; `--import` must run before headless boot; boot must print the expected markers. Owning task: Task 8/9/11.

`packages/core/src/schemas/game-spec.ts`:

```ts
import { z } from 'zod';

const engineSchema = z.enum(['godot', 'unity', 'unreal', 'web']);
const dimensionSchema = z.enum(['2d', '3d']);

export const gameSpecSchema = z
  .object({
    version: z.literal(1),
    project: z
      .object({
        name: z.string().min(1),
        engine: engineSchema,
        godot_version: z.string().optional(),
        dimension: dimensionSchema,
        view: z.string().min(1),
        target: z.array(z.string().min(1)).min(1),
      })
      .passthrough(),
    genre: z
      .object({
        primary: z.string().min(1),
        secondary: z.array(z.string()).default([]),
        template: z.string().min(1),
      })
      .passthrough(),
    scope: z
      .object({
        levels: z.number().int().nonnegative().default(1),
        enemies: z.number().int().nonnegative().default(0),
        bosses: z.number().int().nonnegative().default(0),
        skills: z.number().int().nonnegative().default(0),
        items: z.number().int().nonnegative().default(0),
        quests: z.number().int().nonnegative().default(0),
      })
      .passthrough()
      .default({}),
    systems: z.record(z.boolean()).default({}),
    content: z
      .object({
        language: z.string().default('zh-CN'),
      })
      .passthrough()
      .default({}),
    vision: z.record(z.unknown()).optional(),
    acceptance: z.array(z.string()).default([]),
  })
  .passthrough();

export type GameSpec = z.infer<typeof gameSpecSchema>;

export function parseGameSpec(input: unknown): GameSpec {
  return gameSpecSchema.parse(input);
}
```

```ts
    version: z.string().regex(/^\d+\.\d+\.\d+$/, 'invalid semver'),
    engine: z.enum(['godot', 'unity', 'unreal', 'web']),
    engine_version: z.string().min(1),
    kind: z.enum(['core', 'system', 'ui', 'genre', 'assets']),
    genres: z.array(z.string()).default([]),
    depends: z.record(z.string()).default({}),
    optional_depends: z.record(z.string()).default({}),
    conflicts: z.array(z.string()).default([]),
    provides: z
      .object({
        services: z.array(z.string()).default([]),
        components: z.array(z.string()).default([]),
        events: z.array(z.string()).default([]),
      })
      .default({}),
    requires: z
      .object({
        interfaces: z.array(z.string()).default([]),
      })
      .default({}),
    config_schema: z.string().optional(),
    config_defaults: z.string().optional(),
    autoloads: z.array(autoloadSchema).default([]),
    ui_mounts: z
      .array(

          slot: z.string().min(1),
          scene: z.string().min(1),
          layer: z.number().int().default(0),
        }),
      )
      .default([]),
    input_actions: z.array(z.string()).default([]),
    save_sections: z
      .array(z.object({ key: z.string().min(1), serializer: z.string().min(1) }))

    scenarios: z.array(z.string()).default([]),
    tests: z.array(z.string()).default([]),
    ai_skill: z.string().optional(),
    docs: z.string().optional(),
    license: z.string().default('Apache-2.0'),
    authors: z.array(z.string()).default([]),
  })
```

```ts
import { existsSync, readdirSync, readFileSync } from 'node:fs';
import { join } from 'node:path';
import { parse } from 'yaml';
import { parseModuleManifest } from '../schemas/module-manifest.js';
import type { ModuleRecord, ModuleRegistry } from './types.js';

export class LocalRegistry implements ModuleRegistry {
  private readonly records = new Map<string, ModuleRecord>();

  constructor(modulesDir: string) {
    if (!existsSync(modulesDir)) return;
    for (const entry of readdirSync(modulesDir, { withFileTypes: true })) {
      if (!entry.isDirectory()) continue;
      const manifestPath = join(modulesDir, entry.name, 'module.yaml');
      if (!existsSync(manifestPath)) continue;
      const manifest = parseModuleManifest(parse(readFileSync(manifestPath, 'utf8')));
      this.records.set(manifest.id, { manifest, dir: join(modulesDir, entry.name) });
    }
  }

  get(id: string, range?: string): ModuleRecord | null {
    const record = this.records.get(id);
    if (!record) return null;
    if (range && !record.manifest.version) return null;
    return record;
  }

  list(): ModuleRecord[] {
    return [...this.records.values()];
  }
}
```

`packages/core/src/resolver/graph.ts`:

```ts
export function topologicalSort(
  nodes: string[],
  edges: Map<string, string[]>,
): string[] {
  const result: string[] = [];
  const state = new Map<string, 'white' | 'gray' | 'black'>();
  for (const node of nodes) state.set(node, 'white');

  function visit(node: string, stack: string[]): void {
    const color = state.get(node);
    if (color === 'black') return;
    if (color === 'gray') {
      throw new Error(`cycle:${[...stack, node].join(' -> ')}`);
    }
    state.set(node, 'gray');
    for (const dep of edges.get(node) ?? []) visit(dep, [...stack, node]);
    state.set(node, 'black');
    result.push(node);
  }

  for (const node of nodes) visit(node, []);
  return result;
}
```

`packages/core/src/resolver/resolve-modules.ts`:

```ts
import { satisfies } from 'semver';
import { ResolutionError } from '../errors.js';
import type { GameSpec } from '../schemas/game-spec.js';
import type { TemplateManifest } from '../schemas/template.js';
import type { ModuleRecord, ModuleRegistry } from '../registry/types.js';
import { topologicalSort } from './graph.js';

export interface Resolution {
  modules: ModuleRecord[];
  order: string[];
}

export interface ResolveInput {
  spec: GameSpec;
  template: TemplateManifest;
  registry: ModuleRegistry;
  engine: GameSpec['project']['engine'];
}

export function resolveModules(input: ResolveInput): Resolution {
  const { template, registry, engine } = input;
  const byId = new Map<string, ModuleRecord>();
  const edges = new Map<string, string[]>();

  function add(id: string, range: string | undefined, requiredBy: string | undefined): void {
    const existing = registry.get(id, range);
    if (!existing) {
      const code = requiredBy ? 'MISSING_DEPENDENCY' : 'MISSING_MODULE';
      throw new ResolutionError(code, `module not found: ${id}`, {
        module: id,
        requiredBy: requiredBy ?? 'template',
      });
    }
    if (range && !satisfies(existing.manifest.version, range)) {
      throw new ResolutionError('VERSION_MISMATCH', `module ${id}@${existing.manifest.version} does not satisfy ${range}`, {
        module: id,
        range,
      });
    }
    if (existing.manifest.engine !== engine) {
      throw new ResolutionError('ENGINE_MISMATCH', `module ${id} targets ${existing.manifest.engine}, expected ${engine}`, {
        module: id,
        engine,
      });
    }
    if (byId.has(id)) return;
    byId.set(id, existing);
    edges.set(id, []);
    for (const [dep, depRange] of Object.entries(existing.manifest.depends)) {
      edges.get(id)!.push(dep);
      add(dep, depRange, id);
    }
  }

  for (const id of template.modules.required) add(id, undefined, undefined);

  for (const record of byId.values()) {
    for (const conflict of record.manifest.conflicts) {
      if (byId.has(conflict)) {
        throw new ResolutionError('CONFLICT', `module ${record.manifest.id} conflicts with ${conflict}`, {
          module: record.manifest.id,
          conflict,
        });
      }
    }
  }

  let order: string[];
  try {
    order = topologicalSort([...byId.keys()], edges);
  } catch (error) {
    throw new ResolutionError('CYCLE', (error as Error).message);
  }

  const modules = order.map((id) => byId.get(id)!);
  return { modules, order };
}
```

> The resolver only returns resolved modules and order. The composer builds the lockfile after copying, because it needs the content hash of each module directory (Task 7).

```ts
import { createHash } from 'node:crypto';
import { readdirSync, readFileSync, statSync } from 'node:fs';
import { join, relative } from 'node:path';

function walk(dir: string, result: string[]): void {
  for (const entry of readdirSync(dir, { withFileTypes: true })) {
    const path = join(dir, entry.name);
    if (entry.isDirectory()) walk(path, result);
    else result.push(path);
  }
}

export function hashDirectory(dir: string): string {
  const files: string[] = [];
  walk(dir, files);
  files.sort();
  const hash = createHash('sha256');
  for (const file of files) {
    hash.update(relative(dir, file).replaceAll('\\', '/'));
    hash.update('\0');
    hash.update(readFileSync(file));
    hash.update('\0');
  }
  return `sha256:${hash.digest('hex')}`;
}
```

```ts
import { mkdirSync } from 'node:fs';
import { join } from 'node:path';
import { LocalRegistry } from '../registry/local-registry.js';
import { resolveModules } from '../resolver/resolve-modules.js';
import { loadGameSpec } from '../spec/load-game-spec.js';
import { loadTemplate } from '../spec/load-template.js';
import type { Lockfile } from '../schemas/lockfile.js';
import type { ComposeOptions, ComposeResult } from './types.js';
import { hashDirectory } from './file-hash.js';
import { copyModules } from './copy-modules.js';
import { writeLockfile } from './write-lockfile.js';

export async function composeProject(options: ComposeOptions): Promise<ComposeResult> {
  const spec = loadGameSpec(options.specPath);
  const template = loadTemplate(resolveTemplatePath(options, spec.genre.template));
  mkdirSync(options.outDir, { recursive: true });
  const registry = new LocalRegistry(options.modulesDir);
  const resolution = resolveModules({
    spec,
    template,
    registry,
    engine: spec.project.engine,
  });

  copyModules(options.outDir, resolution.modules);

  const lockfile: Lockfile = {
    version: 1,
    modules: resolution.modules.map((module) => ({
      id: module.manifest.id,
      version: module.manifest.version,
      source: 'local',
      hash: hashDirectory(module.dir),
    })),
  };
  const lockfilePath = writeLockfile(options.outDir, lockfile);

  return {
    outDir: options.outDir,
    order: resolution.order,
    modules: resolution.modules,
    lockfile,
    files: [lockfilePath],
  };
}

function resolveTemplatePath(options: ComposeOptions, templateId: string): string {
  return join(options.templatesDir, templateId, 'template.yaml');
}
```

```ts
import type { CommandRunner } from './runner.js';
import { runCommand } from './runner.js';
import type { GodotInstallation } from './types.js';

export async function detectGodot(options: {
  env?: NodeJS.ProcessEnv;
  runner?: CommandRunner;
} = {}): Promise<GodotInstallation | null> {
  const env = options.env ?? process.env;
  const runner = options.runner ?? runCommand;
  const candidates = [env.GODOT_BIN, 'godot', 'godot4'].filter(Boolean) as string[];

  for (const bin of candidates) {
    try {
      const result = await runner.run(bin, ['--version']);
      if (result.exitCode !== 0) continue;
      const version = result.stdout.trim().split('\n')[0];
      const match = version.match(/^(\d+)\.(\d+)/);
      if (!match) continue;
      return { bin, version, major: Number(match[1]), minor: Number(match[2]) };
    } catch {
      // try the next candidate
    }
  }
  return null;
}
```

```ts
import { readFileSync } from 'node:fs';
import { join } from 'node:path';
import { parseGameManifest, parseLockfile } from '@gamedream/core';
import { detectGodot, findScriptErrors, hasMarker, importProject, runHeadless, type CommandRunner } from '@gamedream/godot';

export interface GateResult {
  status: 'pass' | 'fail' | 'skip';
  message?: string;
}

export interface VerifyReport {
  gates: Record<'G1' | 'G2' | 'G3', GateResult>;
}

export async function verifyCommand(options: {
  projectDir: string;
  env?: NodeJS.ProcessEnv;
  runner?: CommandRunner;
}): Promise<VerifyReport> {
  const gates: VerifyReport['gates'] = {
    G1: { status: 'fail' },
    G2: { status: 'skip', message: 'GODOT_NOT_FOUND' },
    G3: { status: 'skip', message: 'GODOT_NOT_FOUND' },
  };

  try {
    parseLockfile(JSON.parse(readFileSync(join(options.projectDir, 'modules.lock.json'), 'utf8')));
    parseGameManifest(JSON.parse(readFileSync(join(options.projectDir, 'game/game.manifest.json'), 'utf8')));
    gates.G1 = { status: 'pass' };
  } catch (error) {
    gates.G1 = { status: 'fail', message: (error as Error).message };
    return { gates };
  }

  const godot = await detectGodot({ env: options.env, runner: options.runner });
  if (!godot) return { gates };

  const imported = await importProject(options.projectDir, godot, options.runner);
  const importErrors = findScriptErrors(imported);
  if (imported.exitCode !== 0 || importErrors.length > 0) {
    gates.G2 = { status: 'fail', message: importErrors.join('\n') || `exit ${imported.exitCode}` };
    return { gates };
  }
  gates.G2 = { status: 'pass' };

  const run = await runHeadless(options.projectDir, godot, { quitAfter: 300, runner: options.runner });
  const errors = findScriptErrors(run);
  if (run.exitCode !== 0) {
    gates.G3 = { status: 'fail', message: `exit ${run.exitCode}` };
  } else if (errors.length > 0) {
    gates.G3 = { status: 'fail', message: errors.join('\n') };
  } else if (!hasMarker(run, 'GAMEDREAM_BOOT_OK')) {
    gates.G3 = { status: 'fail', message: 'missing GAMEDREAM_BOOT_OK' };
  } else if (!hasMarker(run, 'INVENTORY_COUNT=1')) {
    gates.G3 = { status: 'fail', message: 'missing INVENTORY_COUNT=1' };
  } else {
    gates.G3 = { status: 'pass' };
  }
  return { gates };
}
```

```ts
import { Command } from 'commander';
import { detectGodot } from '@gamedream/godot';
import { doctorCommand } from './commands/doctor.js';
import { composeCommand } from './commands/compose.js';
import { runCommand as runProject } from './commands/run.js';
import { verifyCommand } from './commands/verify.js';
import { printJson, printLine } from './output.js';

export function createProgram(): Command {
  const program = new Command();
  program.name('dream').description('GameDream AI game development assistant').version('0.0.0');

  program
    .command('doctor')
    .description('Check Node and Godot environment')
    .option('--json', 'print JSON')
    .action(async (options: { json?: boolean }) => {
      const report = await doctorCommand();
      if (options.json) printJson(report);
      else {
        printLine(`Node: ${report.node}`);
        printLine(`Godot: ${report.godot ? `${report.godot.version} (${report.godot.bin})` : 'not found'}`);
      }
    });

  program
    .command('compose')
    .requiredOption('--spec <path>')
    .requiredOption('--out <dir>')
    .requiredOption('--modules <dir>')
    .requiredOption('--templates <dir>')
    .option('--json', 'print JSON')
    .action(async (options: { spec: string; out: string; modules: string; templates: string; json?: boolean }) => {
      const result = await composeCommand({
        specPath: options.spec,
        outDir: options.out,
        modulesDir: options.modules,
        templatesDir: options.templates,
      });
      if (options.json) printJson({ outDir: result.outDir, order: result.order });
      else printLine(`Composed ${result.order.length} modules into ${result.outDir}`);
    });

  program
    .command('run')
    .requiredOption('--path <dir>')
    .option('--quit-after <frames>', 'quit guard', '300')
    .action(async (options: { path: string; quitAfter: string }) => {
      const godot = await detectGodot();
      if (!godot) {
        printLine('Godot not found; set GODOT_BIN.');
        process.exitCode = 3;
        return;
      }
      const result = await runProject({
        projectDir: options.path,
        godot,
        quitAfter: Number(options.quitAfter),
      });
      if (result.stdout) printLine(result.stdout);
      if (result.stderr) printLine(result.stderr);
      process.exitCode = result.exitCode;
    });

  program
    .command('verify')
    .requiredOption('--path <dir>')
    .option('--json', 'print JSON')
    .action(async (options: { path: string; json?: boolean }) => {
      const report = await verifyCommand({ projectDir: options.path });
      if (options.json) printJson(report);
      else {
        for (const [gate, result] of Object.entries(report.gates)) {
          printLine(`${gate}: ${result.status}${result.message ? ` (${result.message})` : ''}`);
        }
      }
      const failed = Object.values(report.gates).some((gate) => gate.status === 'fail');
      process.exitCode = failed ? 2 : 0;
    });

  return program;
}
```
