# GameDream Web M0 Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (Native). Steps use checkbox syntax.

**Goal:** Add the second engine track with a dependency-free Web M0 vertical slice: a standalone HTML/Canvas project with a deterministic simulation, player/enemy combat, win condition, and `dream web compose/verify`. Phaser rendering is a later renderer swap; the contract and simulation stay.

**Architecture:** `packages/web` composes `templates/web-m0` and writes `game.json`. `sim.mjs` is a pure, testable game simulation (no DOM); `game.js` renders it on Canvas with keyboard input. `verifyWebProject` runs `node sim.mjs --frames 600` and checks `WEB_BOOT_OK`/`WEB_WIN`. CLI exposes `dream web compose` and `dream web verify`.

**Tech Stack:** TypeScript CLI/package, vanilla HTML/Canvas/ES modules, Node child process for verification. No browser automation or new dependencies.

## Global Constraints

- Web M0 is deterministic and dependency-free; no Phaser/browser install in CI.
- Generated project has `index.html`, `style.css`, `sim.mjs`, `game.js`, `game.json`.
- Markers: `WEB_BOOT_OK`, `WEB_WIN`; exit 1 on loss/error.
- `web compose` refuses overwrite unless `--force`.
- `web verify` fails on missing markers, non-zero exit, or missing files.
- Godot paths unchanged.
