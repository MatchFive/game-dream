# GameDream M2 Combat Depth Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (Native). Steps use checkbox syntax.

**Goal:** Give M2 enemies distinct behavior, add a boss enrage phase, and align loot/items across Godot and Web.

**Architecture:** Campaign enemy data gains `attack_range`; Godot AI uses it and enters an enraged phase for `kind=boss` at ≤50% HP; Web sim mirrors range, phase, and deterministic loot from embedded items/loot content. New `GAMEDREAM_BOSS_PHASE`/`WEB_BOSS_PHASE` markers verify the phase.

**Tech Stack:** Existing content JSON, Godot enemy/gameflow, Web compose/sim; no dependencies.

## Global Constraints

- Wisp attacks from range (~180), guardian/boss use closer ranges; slime stays melee.
- Boss phase once at ≤50% HP: faster, stronger, tinted, marker emitted once.
- Loot content exists for slime/wisp/guardian/boss and Web drops match item names.
- M0/fixture unaffected; Godot/Web markers and autoplay stay green.
- No external assets; existing SVG sheets only.
