# GameDream M2 Content Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (Native). Steps use checkbox syntax.

**Goal:** Expand the shared RPG content to a five-level M2 slice: two enemy variants, two new maps, four kill quests, and a final boss, without engine-specific content forks.

**Architecture:** Extend `templates/rpg-action-m1/content` (shared by Godot and Web): campaign levels/maps/quests/sprites; add wisp/guardian SVG sheets and sprite configs. Update Godot boss marker to detect the boss kind rather than a fixed index. Existing M0/fixture behavior and all engine contracts stay.

**Tech Stack:** JSON content, SVG sprite sheets, Godot gameflow, Web content embedding/sim.

## Global Constraints

- Five levels: clearing→grove→shrine→throne→sanctum; boss is final.
- Enemy kinds slime, wisp, guardian, boss; each has stats and sprite.
- Four kill quests; all completed by autoplay/headless.
- No external art/audio; SVG sheets are local and frame sizes valid.
- M0 remains one arena; fixture unaffected.
- Markers remain the same names; `GAMEDREAM_BOSS` fires on the boss level.
- Update M1/M2 docs and tests; no engine fork.

## Review Focus

1. Content schema validity/map dimensions/spawn safety.
2. Sprite frame bounds/asset paths for new kinds.
3. Quest completion and boss marker semantics.
4. Godot/Web autoplay duration/termination with five levels.
5. M0/M1 tests/docs/regression.
