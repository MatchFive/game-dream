# Studio 视觉简化与路径选择器设计

> 状态：实施中
> 日期：2026-11-27
> 范围：`packages/studio/public` 三个页面、Studio 本地 API

## 1. 目标

1. 从“霓虹科技风”改为 Lovart 式暖白极简：更少颜色、更少光晕、更安静的状态提示。
2. 设置页的路径不再要求手输；文件/文件夹路径提供原生资源管理器选择，同时保留手输能力。
3. 列表型路径（skills / MCP）改为可增删的路径列表，而不是多行文本。

## 2. 视觉系统

### 2.1 颜色

- 背景：暖白 `#F5F2EC`
- 面层：白 `#FFFFFF` / 次要面 `#FAF8F4`
- 文本：墨黑 `#1D1C19`，次要 `#6D675E`，弱化 `#7B756B`
- 边框：`#E5DFD5`，强调边框 `#CFC7BA`
- 主操作：墨黑底白字（不再用亮色大按钮）
- 唯一强调色：低饱和橄榄 `#5F7051`，仅用于选中/进行中/焦点
- 语义色：成功 `#58735B`、警告 `#8F713D`、错误 `#9A5345`、信息 `#64717A`
- 移除：亮青、亮珊瑚、荧光绿、霓虹光晕、彩色渐变

### 2.2 字体与间距

- UI 默认 sans；mono 只用于路径、代码、日志。
- 正文 13px/1.5；标签 11px；辅助 11px；按钮 12px；标题 20–24px。
- 去掉大面积 uppercase + 宽字距；只保留少量 section label。
- 圆角 8–14px；阴影改为低对比柔和阴影。
- 交互控件最小高度 36px，移动端 44px。

### 2.3 主要表面

- 顶栏：暖白半透明、细边框、无渐变。
- 三栏工作区：白面板 + 暖白画布；画布点阵降到低对比。
- 节点：白卡、细边框、柔和阴影；选中用橄榄色细边框，不再发光。
- 连线：中性灰实线，取消荧光虚线。
- 素材 Agent / prompt dock / 对话框：白面层、细边框、柔和阴影。
- 状态只通过小圆点/文字颜色表达，不给整块区域上色。

## 3. 路径选择交互

### 3.1 原生选择器

新增本机 API：

```http
POST /api/dialog
{ "kind": "file" | "folder", "title": "...", "filter": "JSON (*.json)|*.json" }
→ { "path": "D:/..." | null }
```

- 仅 loopback 请求可用；非本机返回 403。
- 仅接受同源 JSON POST（沿用现有 `assertTrustedMutation`）。
- Windows 使用 PowerShell `OpenFileDialog` / `FolderBrowserDialog`（STA）。
- macOS 使用 `osascript choose file/folder`。
- Linux 使用 `zenity` / `kdialog`。
- 不使用 shell 拼接；标题/filter 通过环境变量传入，避免注入。
- 取消返回 `path: null`，不报错。
- 非本机或桌面不可用时返回清晰错误，输入框仍可手输。

### 3.2 设置页

- 单路径：输入框 + “浏览…”按钮。
  - 旧 workflow 文件：文件
  - workflow 目录：文件夹
  - Godot 可执行文件：文件
  - Unity Editor 目录：文件夹
  - 打开已有项目：文件夹
- 列表路径：
  - Skills 根目录：添加文件夹 / 删除
  - MCP 配置：添加文件 / 删除
- 所有路径保留手输，选择器是增强而不是替代。

## 4. 验收

- 三个页面在 1440×900 下呈现暖白极简风格，无霓虹渐变/光晕/大面积高饱和色。
- 文本层级清晰：UI sans，路径/日志 mono，最小可读字号 ≥ 11px（日志 9.5px 以上）。
- 设置页每个路径字段有“浏览…”；列表可增删；取消选择不破坏原值。
- `/api/dialog` 同源 + loopback 校验；测试覆盖命令构造与注入选择的返回路径。
- `typecheck` / `test` / `build` 全绿，截图检查三页。
