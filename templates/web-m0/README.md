# GameDream Web M0

A standalone Phaser 3 prototype generated by GameDream. The project vendors
`vendor/phaser.min.js`; with `--content templates/rpg-action-m1/content` it
embeds the five-level campaign, maps, quests, HUD counts, and
player/enemy/boss/wisp/guardian sprite assets.

## Run

Browsers block ES modules and `fetch('./game.json')` from `file://`, so serve the
directory:

```bash
python3 -m http.server 8080
# open http://localhost:8080
```

WASD / arrows move, J / Space attacks, I opens inventory, Q opens quests, O
opens settings, P pauses, R resets the run, Esc closes panels. Walls block
movement. The camera follows the player within map bounds and zooms in on small
touch screens. Touch devices get an on-screen D-pad, attack button, panel buttons,
and pause menu. The Phaser scene reads the same `sim.mjs` state as the headless verifier. Progress
(level, HP, inventory, quests) is saved in localStorage; music/SFX volumes and
fullscreen preference are saved separately. Audio starts after the first input
and requires no external audio assets.

## Headless verify

```bash
node sim-run.mjs --frames 1800
```

prints `WEB_BOOT_OK` and `WEB_WIN`.

## Screenshot

Open the page in Chrome/Edge, or run `dream web screenshot --path .` for a
headless screenshot. `dream web verify --path . --visual` also checks that the
page is not blank.

## Publish

`dream web package --path . --out ../release` writes a checked static release
with `deployment.json` (content sizes and SHA-256 hashes; the manifest itself is
not listed). Upload the release directory to any static host; see the root
`docs/deploy-web.md`.
