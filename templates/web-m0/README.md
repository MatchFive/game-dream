# GameDream Web M0

A dependency-free Canvas 2D prototype generated by GameDream. With
`--content templates/rpg-action-m1/content` it embeds the three-level campaign,
maps, quests, HUD counts, and player/enemy/boss sprite assets.

## Run

Browsers block ES modules and `fetch('./game.json')` from `file://`, so serve the
directory:

```bash
python3 -m http.server 8080
# open http://localhost:8080
```

WASD / arrows move, J / Space attacks, I opens inventory, Q opens quests, Esc
closes panels. Walls block movement.

## Screenshot

Open the page in Chrome/Edge, or run `dream web screenshot --path .` for a
headless screenshot. `dream web verify --path . --visual` also checks that the
page is not blank.

```bash
node sim-run.mjs --frames 600
```

prints `WEB_BOOT_OK` and `WEB_WIN`.
