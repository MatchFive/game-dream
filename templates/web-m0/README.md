# GameDream Web M0

A dependency-free Canvas 2D prototype generated by GameDream. With
`--content templates/rpg-action-m1/content` it embeds the three-level campaign,
maps, quests, HUD counts, and player/enemy/boss sprite assets.

## Run

Browsers block ES modules and `fetch('./game.json')` from `file://`, so serve the
directory:

```bash
python3 -m http.server 8080
# open http://localhost:8080
```

WASD / arrows move, J / Space attacks.

## Headless verify

```bash
node sim-run.mjs --frames 600
```

prints `WEB_BOOT_OK` and `WEB_WIN`.
