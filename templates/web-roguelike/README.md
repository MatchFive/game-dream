# GameDream Web Roguelike

A standalone Canvas/ESM grid roguelike generated by GameDream.

WASD moves one tile; bump enemies to clear them; reach the green exit. The
shared `sim.mjs` drives both the browser and the headless verifier.

```bash
python -m http.server 8080
node sim-run.mjs --frames 1800
```

The headless run prints `WEB_BOOT_OK` and `WEB_WIN`.
