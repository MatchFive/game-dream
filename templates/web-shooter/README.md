# GameDream Web Shooter

A standalone Canvas/ESM top-down shooter generated by GameDream. The browser
and `sim-run.mjs` share `sim.mjs`, so movement, auto-fire, waves, HP, and the
win condition are identical in both.

## Run

```bash
python -m http.server 8080
# open http://localhost:8080
```

WASD/arrows move. Weapons auto-target the nearest enemy. Clear five waves;
R restarts after win/lose.

## Verify

```bash
node sim-run.mjs --frames 1800
```

prints `WEB_BOOT_OK` and `WEB_WIN`.
