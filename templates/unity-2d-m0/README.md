# Unity 2D M0

Generated by GameDream. Requires Unity 6 (6000.x).

## Run

1. Open this folder with Unity Hub / Unity 6.
2. Open any scene and press **Play**. `GameBootstrap` uses
   `RuntimeInitializeOnLoadMethod`, so it creates the camera, arena, player, enemy,
   and HUD without a scene asset.
3. Move with WASD/arrows, attack with J or Space, restart with R.

Runtime markers: `UNITY_BOOT_OK`, then `UNITY_WIN` or `UNITY_LOSE`.
Headless markers: `UNITY_SIM_OK`, then `UNITY_WIN`, `UNITY_LOSE`, or
`UNITY_TIMEOUT`. A compile error exits before any marker appears.

## Build and screenshot

```text
dream unity build --path <this-folder> --out <this-folder>/Builds/Windows/GameDream.exe
dream unity screenshot --path <this-folder> --out <this-folder>/Screenshots/unity.png
```

`build` creates/updates `Assets/Scenes/Main.unity` and `EditorBuildSettings.asset`,
then builds a Windows 64-bit player. `screenshot` enters play mode, renders the
arena to a PNG, and exits. Both require Unity 6000.x and are opt-in slow runs.

## Headless verification

With Unity installed:

```text
dream unity verify --path <this-folder> --runtime
```

or directly:

```text
Unity -batchmode -quit -projectPath <this-folder> -executeMethod EditorVerifier.Run -logFile -
```

Set `UNITY_BIN` (or pass `--unity`) if Unity is not in a common Hub location.

Exit 0 and a fresh `UNITY_WIN` means the pure C# `GameSim` completed the M0 arena.
`dream unity verify --path <this-folder>` performs static project/marker checks and
does **not** claim a Unity runtime run.

## Limitations

- This is a source scaffold; GameDream does not bundle Unity or its binaries.
- The project uses legacy `Input.GetKey`; set Active Input Handling to include the
  legacy Input Manager if the editor reports input errors.
- Build settings and a saved scene are intentionally not generated yet; the runtime
  bootstrap makes Play mode work without them.
- Unity creates `Library/`, `Temp/`, `Logs/`, and package lock files on first open;
  a newer Unity may also upgrade `ProjectSettings/ProjectVersion.txt`.
