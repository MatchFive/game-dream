# GameDream Web Survivor

A standalone Canvas/ESM survivor demo generated by GameDream. It shares
`sim.mjs` with the headless verifier, so the same auto-attack/spawn/timer loop is
used by the browser and `sim-run.mjs`.

## Run

```bash
python -m http.server 8080
# open http://localhost:8080
```

WASD/arrows move; attacks are automatic; R restarts after win/lose. Elite
enemies spawn periodically, the bolt evolves into `storm` at weapon level 3,
and coins persist in `localStorage` for meta damage/HP upgrades.

## Audio

When the project contains `game/build-assets/manifest.json` with an audio asset
(for example after selecting a BGM in Studio), the game loads that file, loops
it, and wires the existing Music slider to its volume. Browsers still require a
first click/keypress before playback, so the track starts on first interaction.
Without a staged BGM the game stays silent.

## Verify

```bash
node sim-run.mjs --frames 1800
```

prints `WEB_BOOT_OK` and `WEB_WIN` after the survival timer.
