# GameDream Web Survivor

A standalone Canvas/ESM survivor demo generated by GameDream. It shares
`sim.mjs` with the headless verifier, so the same auto-attack/spawn/timer loop is
used by the browser and `sim-run.mjs`.

## Run

```bash
python -m http.server 8080
# open http://localhost:8080
```

WASD/arrows move; attacks are automatic; R restarts after win/lose.

## Verify

```bash
node sim-run.mjs --frames 1800
```

prints `WEB_BOOT_OK` and `WEB_WIN` after the survival timer.
