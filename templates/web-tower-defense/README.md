# GameDream Web Tower Defense

A standalone Canvas/ESM tower-defense slice generated by GameDream.

Towers auto-build/upgrade and fire at enemies following the path. The shared
`sim.mjs` drives the browser and the headless verifier.

```bash
python -m http.server 8080
node sim-run.mjs --frames 1800
```

The headless run prints `WEB_BOOT_OK` and `WEB_WIN`.
