# GameDream Web Puzzle

A standalone Canvas/ESM grid puzzle generated by GameDream.

Push crystals onto all targets in two chambers. The shared `sim.mjs` drives the
browser and the headless verifier.

```bash
python -m http.server 8080
node sim-run.mjs --frames 1800
```

The headless run prints `WEB_BOOT_OK` and `WEB_WIN`.
