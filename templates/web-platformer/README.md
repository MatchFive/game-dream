# GameDream Web Platformer

A standalone Canvas/ESM platformer demo generated by GameDream. The browser and
`sim-run.mjs` share `sim.mjs`, so movement, collision, coins, and the win
condition are identical in both.

## Run

```bash
python -m http.server 8080
# open http://localhost:8080
```

A/D or arrows move, W/Up/Space jumps, R restarts. The run has three stages:
Rooftops → Foundry → Skyline, each with its own platforms, coins, and flag.

## Verify

```bash
node sim-run.mjs --frames 1800
```

prints `WEB_BOOT_OK` and `WEB_WIN`.
